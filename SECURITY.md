# Security

If you discover a security issue in ascii-render, please report it privately
so we can fix it before disclosure.

## How to report

Send a description of the issue to the project maintainers through a private
channel appropriate for the project. Please include:

- A description of the vulnerability
- Steps to reproduce it
- The affected version or commit
- Any ideas for mitigation

## What to expect

- Acknowledgment of your report as soon as practical
- A timeline for fixes when possible
- Credit in the release notes if you want it and if it is appropriate

## Safe disclosure

Please avoid sharing exploitable details in public issues until a fix is
available. If you are unsure whether something is a security issue, report it
anyway and we will help triage it.

## Supported versions

Only the current tracked version on the main branch is actively supported for
security fixes.
